## 🐛 The Problem

### Error Message
```
=> ERROR [5/5] COPY . .   71.9s
------
 > [5/5] COPY . .:
------
failed to solve: ResourceExhausted: failed to create temp dir: 
mkdir /var/lib/docker/tmp/buildkit-mount1991085525: no space left on device
```

### Root Cause
**Docker was copying 2.3GB of XML files into the app container!**

```
cfr_xmls/
  ├── CFR-1996-title21-vol1.xml
  ├── CFR-1996-title21-vol2.xml
  ├── ... (671 files total)
  └── CFR-2025-title50-vol13.xml

Total: 2.3GB being copied!
```

**Why This Is Wrong:**
- XMLs should be MOUNTED via volumes, not COPIED
- XMLs are only needed in Airflow container
- App container doesn't need XMLs
- Copying 2.3GB every build is wasteful

## 🎯 Why This Works

### Docker Volume Mounting (Correct Way)
```yaml
# In docker-compose.yml
services:
  airflow-webserver:
    volumes:
      - ${CFR_XML_PATH:-./cfr_xmls}:/opt/airflow/external_data:ro
      # XMLs are MOUNTED (read-only, shared from host)
```

**Benefits:**
- ✅ No copying (instant access)
- ✅ No disk space waste
- ✅ Updates reflected immediately
- ✅ Shared across containers

### Docker COPY (Wrong for XMLs)
```dockerfile
# In Dockerfile
COPY . .
# This would copy EVERYTHING including XMLs!
```

**Problems:**
- ❌ Copies 2.3GB every build
- ❌ Wastes disk space
- ❌ Slows build time
- ❌ Embedded in image (can't update)

## 📝 Lessons Learned

### Best Practices for Docker

1. **Use `.dockerignore`**
   - Exclude large files
   - Exclude build artifacts
   - Exclude data files

2. **Use Volumes for Data**
   - XMLs, CSVs, databases
   - Logs and temp files
   - User uploads

3. **COPY Only Code**
   - Source files (*.ts, *.tsx)
   - Config files
   - Static assets (small ones)

4. **Keep Images Small**
   - Faster builds
   - Less disk space
   - Faster deployments

## 🔍 How to Avoid This

### Check Build Context Size
```bash

docker build --progress=plain --no-cache .

# Check .dockerignore is working
du -sh . 
# Should be ~4MB, not 2.3GB!
```

### Add Exclusions Proactively
```dockerignore
# Data directories
data/
uploads/
downloads/

# Archives
*.zip
*.tar.gz
*.rar

# Large files
*.xml
*.csv
*.json (if large)

# Databases
*.db
*.sqlite
```
